## 正文(直接粘贴)

【配图 1:封面首图 wechat-cover.png(也可作首图)】

很多同学想练网络安全,却卡在同一个问题上:真实环境不敢碰,沙箱又嫌重——要虚拟机、要靶场、要一堆配置。

今天推荐一个轻量解法:**攻防实验台**。它把完整的「攻击发生 → 自动封禁 → 后续请求被拒」闭环,浓缩进一部普通手机,所有流量只走本机回环(127.0.0.1),不涉及任何外部目标。

【配图 2:演练页截图(手机截屏:①-⑥ 按钮 + 事件流)】

**三步上手**

1. 下载 APK(约 6MB,文末二维码),安装即用,无需 Root;
2. 打开「演练」页,①-⑥ 顺序点:启动弱口令靶标 → 模拟爆破 → 启动防御;
3. 看着事件流滚动:每次失败登录都被记录,600 秒窗口内失败满 5 次,来源 IP 立即被封禁,后续请求全部返回 403——就是 fail2ban 的工作方式,只不过被演示的"攻击者"和"受害者"都在你手里。

【配图 3:事件流截图(青色 $ 命令 + 行尾 @本机靶标 标注)】

**不止是演示:端侧 NPU 告警分诊**

应用内置一个轻量分诊模型:在天玑(MediaTek)平台上走 NPU(MDLA)推理,其它机型自动回退 GPU/CPU。把一段告警文本丢给它,几毫秒内输出:类别(正常业务/侦察探测/攻击威胁/钓鱼欺诈)、严重度、是否需要人工研判、建议动作。所有推理在本机完成,数据不出手机。

【配图 4:分诊结果截图(手动分诊或 SSH 告警分诊)】

**自有服务器也能参演(需授权)**

如果你有自己的一台服务器(或已获得书面授权的主机),可以在「SSH目标」页把它设为演练目标机:连接测试 → 防护检查 → 部署 fail2ban 实验规则 → 拉取失败登录告警并分诊 → 封禁/解封。口令尝试环节内置小字典、每次都要授权确认、上限 20 次——故意设计得"克制",因为这是教学工具,不是攻击工具。

【配图 5:SSH 目标页截图(可选用)】

**安全边界(重要)**

· 模拟攻击永远只指向本机回环靶标,流量不出手机;
· SSH 演习仅限你本人拥有或已获书面授权的设备;
· 项目开源(Apache-2.0),严禁用于任何未授权目标。
